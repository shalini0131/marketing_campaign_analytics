# Data Dictionary — Marketing Campaign Analytics

This document defines the tables and columns contained in the `marketing_analytics` database.

---

## 1. Table: `sessions`
Derived from the UCI "Online Shoppers Purchasing Intention" dataset, representing session-level user behavior on the e-commerce website.

| Column Name | Data Type | Key | Description / Range | Example Value |
| :--- | :--- | :--- | :--- | :--- |
| `session_id` | `INT` | Primary Key | Unique identifier for the user session | `12` |
| `administrative` | `INT` | - | Number of pages visited related to account/admin pages | `2` |
| `administrative_duration` | `DECIMAL(10,2)` | - | Total time spent (seconds) on administrative pages | `54.50` |
| `informational` | `INT` | - | Number of pages visited related to informational/about pages | `1` |
| `informational_duration` | `DECIMAL(10,2)` | - | Total time spent (seconds) on informational pages | `15.00` |
| `product_related` | `INT` | - | Number of pages visited related to product pages | `14` |
| `product_related_duration` | `DECIMAL(12,2)` | - | Total time spent (seconds) on product pages | `840.25` |
| `bounce_rate` | `DECIMAL(5,4)` | - | Percentage of visitors leaving immediately from that page | `0.0200` |
| `exit_rate` | `DECIMAL(5,4)` | - | Percentage of visits ending on this page | `0.0450` |
| `page_values` | `DECIMAL(10,4)` | - | Average value of the page visited (transaction value proxy) | `18.5200` |
| `special_day` | `DECIMAL(3,2)` | - | Proximity to a holiday or special day (0.0 to 1.0) | `0.00` |
| `month` | `VARCHAR(20)` | - | Month of the session | `Nov` |
| `operating_system` | `INT` | - | System identifier code | `2` |
| `browser` | `INT` | - | Browser identifier code | `2` |
| `region` | `INT` | - | Geographic region identifier code | `1` |
| `traffic_type` | `INT` | - | Traffic source identifier code | `2` |
| `visitor_type` | `VARCHAR(50)` | - | Visitor category (`New_Visitor`, `Returning_Visitor`, `Other`) | `New_Visitor` |
| `weekend` | `BOOLEAN` | - | Indicates if visit occurred on a weekend | `TRUE` |
| `revenue` | `BOOLEAN` | - | Target variable: session ended in purchase | `FALSE` |
| `channel` | `VARCHAR(50)` | - | Mapped marketing channel based on traffic type | `Paid Search` |
| `engagement_score` | `DECIMAL(6,2)` | - | Derived session activity index based on page views | `22.40` |
| `visitor_segment` | `VARCHAR(50)` | - | Standardized visitor type (`New`, `Returning`, `Other`) | `New` |
| `day_type` | `VARCHAR(20)` | - | Weekend/Weekday designation | `Weekend` |
| `converted` | `TINYINT` | - | Conversion indicator (0 = No purchase, 1 = Purchase) | `1` |

---

## 2. Table: `campaigns`
Tracks individual marketing campaigns, budget spends, and performance aggregates.

| Column Name | Data Type | Key | Description | Example Value |
| :--- | :--- | :--- | :--- | :--- |
| `campaign_id` | `INT` | Primary Key | Unique campaign identifier | `101` |
| `campaign_name` | `VARCHAR(100)` | - | Descriptive name of the campaign | `Search_Brand_Alpha` |
| `channel` | `VARCHAR(50)` | - | Associated marketing channel | `Paid Search` |
| `budget` | `DECIMAL(12,2)` | - | Allocated ad spend budget in GBP (£) | `45000.00` |
| `impressions` | `INT` | - | Total times ad was displayed | `850000` |
| `clicks` | `INT` | - | Total times ad was clicked | `42000` |
| `conversions` | `INT` | - | Number of resulting purchases | `7845` |
| `revenue` | `DECIMAL(14,2)` | - | Revenue generated by the campaign in GBP (£) | `882562.50` |

---

## 3. Table: `touchpoints`
Simulates user conversion pathways over time to calculate attribution.

| Column Name | Data Type | Key | Description | Example Value |
| :--- | :--- | :--- | :--- | :--- |
| `touchpoint_id` | `INT` | Primary Key | Auto-incrementing unique touchpoint identifier | `1452` |
| `user_id` | `VARCHAR(50)` | - | Unique customer identifier | `USR_10015` |
| `channel` | `VARCHAR(50)` | - | Marketing channel for this touchpoint | `Paid Search` |
| `touchpoint_order` | `INT` | - | Index of this touchpoint in the journey (1st, 2nd, etc.) | `2` |
| `total_touchpoints` | `INT` | - | Total touchpoints in the journey prior to purchase | `3` |
| `days_before_conversion` | `DECIMAL(5,2)` | - | Time duration (days) between touchpoint and purchase | `4.25` |
| `revenue` | `DECIMAL(10,2)` | - | Final transaction revenue from conversion | `154.50` |
| `converted` | `TINYINT` | - | Flag indicating if this journey ended in purchase | `1` |
